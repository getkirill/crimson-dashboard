Welcome to Crimson Dashboard!

Crash course / How to use:

- On the left side of the screen there is a crimson-colored toolbar.
  Hover over it to expand.
- There are three modes of operation: Interact, Select, and Add
        - Interact allows you to modify fields and click buttons.
          It's the default mode of operation.
        - Select allows you to move elements with left mouse button,
          and change or remove elements with right mouse button.
        - Add allows you to create more elements.
